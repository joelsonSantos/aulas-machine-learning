Notas do orador

Apresente o objetivo: ao final, os alunos devem saber o que são os parâmetros a e b, o que é um resíduo e por que minimizamos a soma dos erros quadráticos. A aula segue a ordem do notebook aula2-regressao-linear.ipynb; cada gráfico aqui é a versão interativa de uma célula de lá.

Analogia de abertura: ajustar uma reta é como posicionar uma régua sobre pontos marcados num papel quadriculado. Hoje vamos descobrir como medir se a régua está bem posicionada.

Horas de estudo e notas

  • Mais horas tende a significar nota maior

  • Variável explicativa x, variável alvo y
import pandas as pd

Destaque a nomenclatura: x (horas) é a variável explicativa, y (nota) é o alvo. Como o alvo é numérico e contínuo, o problema é de regressão, não de classificação. Os pontos deste slide são exemplos no mesmo formato do arquivo da aula.

Fase 3 · Parâmetro a

O intercepto desloca a reta

f(x) = a + x
  • a é o valor de f quando x = 0
  • a > 0 sobe a reta; a < 0 desce
  • A inclinação não muda: retas paralelas
for a in np.linspace(-5, 5, 51):
    plt.plot(x, x)
    plt.plot(x, a + x, '--')

Notas do orador

Este é o primeiro laço animado do notebook. Arraste o controle e peça que os alunos observem onde a reta vermelha cruza o eixo vertical: é sempre em a.

Analogia: o intercepto é a taxa fixa de um táxi, cobrada antes de rodar o primeiro quilômetro. No nosso problema, seria a nota esperada de quem estudou zero horas.

Fase 4 · Parâmetro b

A inclinação gira a reta

f(x) = b · x
  • b é quanto y muda quando x aumenta 1
  • b = 1 reproduz a identidade
  • b = 0 gera uma reta horizontal
  • Sem a, toda reta passa pela origem
for b in np.linspace(0, 5, 51):
    plt.plot(x, b * x, '--')

Notas do orador

O pequeno triângulo no gráfico mostra a inclinação: um passo de 1 em x provoca um passo de b em y. Esse é o significado prático de b no modelo: pontos de nota ganhos por hora adicional de estudo.

Analogia: b é o preço por quilômetro do táxi. Note que, sem o intercepto, a reta fica presa na origem, o que motiva combinar os dois parâmetros.

Fase 5 · Os dois juntos

Toda reta é a + b·x

f(x) = a + b · x
  • a controla a altura, b controla o ângulo
  • Dois números descrevem qualquer reta não vertical
  • Aprender o modelo = escolher a e b
for a in range(0, 5):
    for b in np.linspace(0, 5, 51):
        plt.plot(x, a + b * x, '--')

Notas do orador

Este slide reproduz o laço duplo do notebook: para cada a inteiro, b varre de 0 a 5. Reforce que o espaço de todas as retas possíveis é bidimensional, um plano de pares (a, b).

Frase-chave: "treinar uma regressão linear é procurar, nesse plano, o par (a, b) mais adequado aos dados". Falta definir o que significa "mais adequado".

  • Somar resíduos não funciona: eles se cancelam

Notas do orador

Os traços vermelhos são os resíduos. Mostre que existem retas claramente ruins, por exemplo inclinadas demais, cuja soma de resíduos dá perto de zero, porque erros positivos e negativos se anulam. Experimente a = 4,9 e b = 0.

Analogia: um termômetro que marca 5 °C a mais de dia e 5 °C a menos à noite tem erro médio zero, mas não serve. Precisamos de uma medida em que todo erro conte como prejuízo.

Fase 8 · Erro quadrático

Somar os quadrados dos resíduos

SSE = Σ (yi − ŷi)2
  • O quadrado torna todo erro positivo
  • Erros grandes pesam mais que os pequenos
  • Cada quadrado no gráfico é um termo da soma
  • Melhor reta: menor área total
y_hat = a + b * data['Horas']
sse = ((data['Notas'] - y_hat) ** 2).sum()
SSE atual = mínimo possível =

Notas do orador

Esta é a visualização geométrica do erro quadrático: cada resíduo vira o lado de um quadrado, e o SSE é a soma das áreas. Ao mover a reta, os quadrados encolhem e crescem. A barra vermelha compara o SSE atual com o menor valor possível.

Por que o quadrado e não o valor absoluto? Ele penaliza mais os erros grandes e gera uma função suave, com derivada em todo ponto, o que permite achar o mínimo com uma fórmula fechada. Analogia: uma multa que cresce mais que proporcionalmente ao excesso de velocidade.

Fase 9 · Função de custo

O mapa do erro no plano (a, b)

Mapa de calor da função de custo: cada posição do mapa é uma reta candidata, e a cor é o SSE dessa reta. É a função que vamos minimizar, não o gradiente.

J(a, b) = Σ (yi − a − b·xi)2
  • Eixo horizontal: a; eixo vertical: b
  • Cor mais intensa: SSE menor
  • O vale tem um único fundo: o mínimo
  • Clique ou arraste no mapa para escolher a reta
SSE menorSSE maior
a = b = SSE = ★ mínimo

Notas do orador

Este gráfico não aparece no notebook. Deixe claro que é um mapa de calor da função de custo J(a, b), não o gradiente: o eixo horizontal é a, o vertical é b, e a cor é o SSE da reta correspondente. O gradiente seria a direção de maior subida nesse terreno, assunto que fica para depois. Arraste no mapa: o gráfico menor abaixo mostra a reta que corresponde ao ponto escolhido.

Analogia: um terreno em formato de tigela. Encontrar a melhor reta é encontrar o ponto mais baixo do terreno. Como a função é quadrática em a e b, a tigela é convexa e tem um único fundo. A mesma ideia de custo e de mínimo reaparece na próxima aula, de regressão logística.

Fase 10 · Mínimos quadrados

A solução tem fórmula fechada

b = Σ(xi−x̄)(yi−ȳ) / Σ(xi−x̄)2
a = ȳ − b · x̄
  • Derivadas de J iguais a zero levam a essas fórmulas
  • A reta ótima passa por (x̄, ȳ)
xm, ym = x.mean(), y.mean()
b = ((x - xm) * (y - ym)).sum() / ((x - xm) ** 2).sum()
a = ym - b * xm

x̄ = ȳ = a* = b* = SSE =

Notas do orador

Explique sem demonstrar todos os passos: derivamos J em relação a a e a b, igualamos a zero e resolvemos o sistema de duas equações. O resultado são as fórmulas ao lado. O botão anima a reta atual até a solução ótima e o ponto marcado é a média (x̄, ȳ), por onde a reta ótima sempre passa.

Interpretação de b: covariância entre x e y dividida pela variância de x. Analogia: b mede quanto x e y "andam juntos" em relação a quanto x varia sozinho.

Fase 12 · Generalização

Várias features: regressão múltipla

ŷ = a + b1·x1 + b2·x2 + … + bp·xp
  • Com 2 features, a reta vira um plano; com p, um hiperplano
  • bj: efeito de xj com as demais features fixas
  • O critério não muda: minimizar o SSE
  • Forma matricial: ŷ = Xβ, com β = (XᵀX)⁻¹Xᵀy
X = data[['Horas', 'Sono']]   # 2 colunas
modelo = LinearRegression().fit(X, data['Notas'])
modelo.intercept_, modelo.coef_     # a, [b1, b2]
arraste para girar
a = b1 (horas) = b2 (sono) = SSE =

Notas do orador

Até aqui usamos uma feature e ajustamos uma reta. Na prática, a nota depende de vários fatores. Com duas features (horas de estudo e horas de sono), o modelo vira um plano no espaço 3D, e o resíduo continua sendo a distância vertical de cada ponto até a superfície. Gire o gráfico e mostre que, vista de lado, cada "fatia" do plano é uma reta como as anteriores. Os dados deste slide são exemplos: a coluna "Sono" não existe em notas.csv.

Interpretação: b1 é quanto a nota muda por hora extra de estudo mantendo o sono fixo. Analogia: o preço de um apartamento depende da área e do número de quartos. Cada coeficiente mede o efeito de uma característica com as outras iguais.

Acima de três dimensões não conseguimos desenhar, mas a matemática é a mesma: X ganha uma coluna por feature e a solução de mínimos quadrados vem de (XᵀX)⁻¹Xᵀy. No scikit-learn, o código só muda na lista de colunas passada ao fit.

Síntese

O caminho da aula

1. Modelo

ŷ = a + b·x: a desloca, b inclina. Com p features, ŷ = a + b₁x₁ + … + bₚxₚ define um hiperplano.

2. Erro

Resíduo e = y − ŷ. Somamos os quadrados para que nenhum erro se cancele.

3. Custo

J(a, b) é uma tigela convexa no plano dos parâmetros, com um único mínimo.

4. Ajuste

Mínimos quadrados resolve J em fórmula fechada; LinearRegression faz o mesmo.

5. Previsão

predict aplica a reta a novos alunos; fora da faixa observada, a previsão é extrapolação.
